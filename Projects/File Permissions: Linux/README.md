# File Permissions: Linux
## Overview
I completed this project as part of the Google Cybersecurity Professional Certificate course.

This project involved being part of a fictional organisation's research team. My job was to ensure that members of the research team were authorised with the appropiate permissions. This helped keep the system secure.

My tasks included examining existing file system permissions, determine if the permissions match the authorisation that should be given and modify the permissions to authorise the appropiate users and remove unauthorised access if required. 

## Objectives
- Examine existing file system permissions
- Understand how permissions are represented in Linux
- Modify permissions using the ```bash chmod``` command
- Apply the principle of least privilege

## Skills
- Using Linux command line
- Managing file permissions
- Principle of least privilege
- Technical documentation

## Commands used
- ```bash cd```
- ```bash ls```
- ```bash ls -la```
- ```bash chmod```

## Outcome
After reviewing the existing permissions on the organisations file system, I identified permissions that didn't comply with the organisations policy and updated these permissions using Linux commands. These updates helped ensure that users had the permissions required to perform their roles only. Reducing the risk of unnecessary access and therefore making the system more secure.
