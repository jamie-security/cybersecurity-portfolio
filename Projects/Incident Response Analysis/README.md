# Incident Response Analysis

## Overview 

I completed this project as part of the Google Cybersecurity Professional Certificate course.

The project required me to create an incident report for a fictional multimedia company that offers web design services, graphic design, and social media marketing solutions to small businesses. The company had recently experienced a Denial of Service attack. 

As the security analyst for the company, I had to create a plan to improve the company's network security, using the NIST cybersecurity framework (CSF) as a guide. 

## Objectives
- Analyse a Denial of Service (DoS) attack incident
- Apply the NIST cybersecurity framework (CSF)
- Recommend improvements to network security

## Skills Demonstrated
- Incident response
- NIST cybersecurity framework (CSF)
- Network analysis
- Technical documentation

## Outcome
My analysis identified weaknesses in the company's network security. An ICMP flood attack was able to be conducted as a result of a misconfigured firewall. My recommendations included the setting up of network monitoring software as well as improved firewall configuration.
