# Security Audit Review

## Overview of project

I completed this project as part of the Google Cybersecurity Professional Certificate course.

I had to review the security posture of a fictional organisation (Botium Toys). To conduct my review, I had to analyse a security audit created by Botium Tools and evaluate their security controls and their compliance to domestic and international laws.

## Objectives
- Assess existing security controls and identify missing ones
- Evaluate compliance to domestic and international laws (PCI DSS and GDPR)
- Recommend improvements to reduce risk

## Skills demonstrated
- Security auditing
- Risk assessments
- Technical documentation

## Outcome
After analysing Botium Toys' existing security controls, I was able to identify missing security measures and gaps in compliance with laws. I produced recommendations to improve Botium Toys' overall security posture.

More detail on my findings can be found in my findings.md document, found within the projects folder.
