# Security Audit Review

## Overview 

I completed this project as part of the Google Cybersecurity Professional Certificate course.

The project required me to review the security posture of a fictional organisation (Botium Toys). To conduct my review, I analysed a security audit created by Botium Toys and evaluate their security controls and their compliance with industry standards and regulations.

## Objectives
- Assess existing security controls and identify missing ones
- Evaluate compliance with industry standards and regulations (PCI DSS and GDPR)
- Recommend improvements to reduce risk

## Skills Demonstrated
- Security auditing
- Risk assessment
- Technical documentation

## Outcome
After analysing Botium Toys' existing security controls, I was able to identify missing security measures and compliance gaps. I produced recommendations to improve Botium Toys' overall security posture.
